Dev Log · #026

작업파이프라인 대변화

ChatGPT(채코치) v5.6, 코덱스 작업 통합 — 새 루프의 첫 실전 테스트

2026년 7월 20일

복붙 작업의 시대가 끝났다

이번에 작업 파이프라인이 한 단계 진화했다. 지금까지는 채코치와 회의하고, 나온 아이디어를 다시 손으로 옮겨 코드에 반영하는 과정이 필요했다. 이제는 그 중간 단계가 사라졌다.

새로운 루프는 이렇다.

  • 김작이 방향을 결정한다
  • 채코치가 직접 구현하고, 커밋하고, push까지 끝낸다
  • GitHub Desktop에서 Fetch → Pull
  • Godot에서 F5로 바로 확인

기획과 판단, QA에만 집중하면 되는 구조다. 복붙 작업은 크게 줄었고, 개발 속도는 눈에 띄게 빨라졌다.

첫 실전 테스트 — 세력 선택 화면 배경

이번 변화를 검증하기 위해 실제로 작업 하나를 맡겼다. 세력 선택 화면에 들어갈 테스트용 배경 이미지 적용이었다. 동아시아 전장을 담은 일러스트를 화면 프레임에 맞춰 배치하는 작업이었다.

결과는 기대 이상이었다. 채코치가 방향을 이해하고, 실제로 파일을 만들고 커밋하고 push까지 한 번에 처리했다. Pull 받아서 Godot F5로 열어보니 화면에 바로 반영되어 있었다.

버그 하나, 그리고 "조선"으로 통일

다만 확인 과정에서 자잘한 버그 하나가 눈에 띄었다. 세력 표기가 "한성" 또는 "한성세력"으로 되어 있었던 것. 고구려·신라·백제는 제대로 표기되어 있었는데 한 곳만 어긋나 있었다.

김작그림에서 자잘한 버그 하나 더 수정해. 세력에 한성 / 한성세력이라고 되어 있는데 이거 조선으로 바꿔야 해. 나머진 고구려, 신라, 백제로 되어 있어.

채코치수정 완료했어. 사용자 표기를 모두 조선으로 통일했어. 시작 화면은 "한성 | 조선 | 시작 도시: 한성"으로, 시작 세력 기준 데이터도 faction_label을 조선으로 바꿨고, 내부 세력 ID와 시작 도시 한성은 그대로 유지했어. 로컬 커밋 f5e6411, 관련 없는 파일은 제외했어.

바로 push까지 요청했다.

채코치푸시 완료했어. 커밋 fc0954cd. 한성 세력을 조선으로 변경했고, 시작 화면 씬과 세력 기준 데이터 파일을 수정했어. GitHub Desktop에서 Fetch origin → Pull origin 하고 Godot에서 F5 하면 바로 확인할 수 있어.

Fetch, Pull, Push — 택배로 정리하기

Fetch와 Pull의 차이가 헷갈려서 물어봤더니, 채코치가 비유 하나로 깔끔하게 정리해줬다.

채코치Fetch origin은 GitHub에 새 변경이 있는지 확인하고 정보만 가져오는 거야. 이때는 아직 Godot 프로젝트 파일이 바뀌지 않아. Pull origin은 확인된 새 변경을 실제로 로컬 폴더에 적용하는 거고, 이때 Godot 파일도 바뀌어. Push origin은 반대로 로컬에서 만든 변경을 GitHub에 올리는 거야.

채코치쉽게 비유하면 Fetch는 택배가 도착했는지 조회하는 거고, Pull은 택배를 받아서 방에 가져오는 거고, Push는 내가 택배를 GitHub로 보내는 거야.

Fetch = 택배 조회 · Pull = 택배 수령 · Push = 택배 발송

완성된 화면

버그 수정까지 반영된 뒤 실제 인게임 화면을 확인했다. 세력 선택 UI 위로 배경이 자연스럽게 깔렸고, 표기도 전부 "조선"으로 통일되어 있었다.

채코치이제 작업 흐름이 완전히 잡혔어. 여기서 회의하고 수정 요청하면, 내가 구현하고 커밋하고 push까지 끝내고, 김작은 Fetch, Pull 받아서 Godot F5로 확인만 하면 돼. 이 루프로 쭉 가면 복붙 작업은 크게 줄고 개발 속도는 훨씬 빨라질 거야.
