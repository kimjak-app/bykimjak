EASTWAR Dev Log #005

Building the Battle — The Battlefield Came First

May 1, 2026

In #004, the structure was settled. Core handles the logic, Phaser handles the visuals, HTML handles the info panels. Now it was time to actually build it.

Honestly, even after finishing the design, I wasn't sure it would work. The only way to find out was to make it.

First, Opening the Path

v0.2 Battle Scene MVP

The first goal was simple: enter the battle screen, resolve the outcome, and return to the world map. Before anything else, this loop had to work.

World map → attack → enter battle → Phaser canvas → win/lose → return → reflect conquest. The moment this loop completed, it finally felt like a game. Just taking Pyeongyang — but still.

Porting the Godot Battle to the Web

v0.2-1 · v0.2-2

Next came the real battle. The grid-based combat system built in Godot had to be ported to Phaser. Select unit → show movable tiles → move → attack enemy → enemy reacts → victory/return. When this started running in the browser, it began to feel like an actual strategy game.

And the heroes arrived. Yi Sun-sin, Jeong Do-jeon, Nobunaga, Kenshin. The first 2v2 battle.

This is where EASTWAR separates from other games. Not generic units — heroes with unique signature skills. Yi Sun-sin's Crane Wing Barrage, Jeong Do-jeon's Reform Decree, Nobunaga's Arquebus Volley, Kenshin's Charge. These aren't skills other generals can learn. They belong to one hero and one hero only.

The hero stats from Godot — troops, power, intelligence, attack, defense, movement — were carried over exactly. Attack and defense aren't fixed values either; they're calculated from power and intelligence formulas. The numbers started to feel alive.

The Battle Got Deeper

v0.2-3 · v0.2-4

The reason Godot battles felt so intense came down to one thing: facing direction. Hitting from the front, flank, or rear all deal different damage. A rear attack lands 1.3x. That one mechanic creates tactical depth. Add counterattack, guard stance, and wait — and suddenly this wasn't just about attacking. It was about knowing when to hold and when to wait.

Then came the moment for intelligence-type heroes like Jeong Do-jeon. The stratagem system — Confusion and Unrest. The higher the intelligence, the longer and more reliably these land. The game started showing that not every battle is won by force.

The AI Couldn't Be Stupid

v0.2-5

Adding auto-battle came with one rule: a dumb AI makes for a dull game. Each hero got a behavioral role. Yi Sun-sin holds range and looks for barrage opportunities. Jeong Do-jeon supports allies. Kenshin charges forward. Even in auto mode, the heroes act like themselves.

The Battlefield Became Visible

v0.2-6 · v0.2-6b

Last came the visuals. Unit images replaced the plain circles. A battlefield background was added — East Asian terrain with rivers, trees, a watchtower, and a gate.

At this stage, one thing mattered above all: allies and enemies had to be readable at a glance. Blue banner — allies. Red banner — enemies. Which nation they represent came later. The battlefield had to be legible first.

The layout came together too — battle log on the left, battlefield in the center, unit info on the right, command bar fixed at the bottom. Once the screen was organized, the battle finally looked like a game.

The battle engine foundation is complete. Next: the enemy takes their turn on the world map — they're coming for us now.
