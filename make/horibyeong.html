01 / 하나의 시퀀스를 끝까지

《호리병》은 AI 영화나 드라마로 발전시키기 위해 기획 중인 IP 콘텐츠다. 이번 트레일러는 전반부에서 실사에 가까운 질감을 최대한 살리고, 후반부에서는 대규모 장면을 어디까지 표현할 수 있는지 시험하기 위해 제작했다.

기존 작업들이 작품의 여러 장면을 압축해 소개하는 트레일러에 가까웠다면, 이번에는 하나의 시퀀스를 처음부터 끝까지 이어 만드는 데 중점을 뒀다.

등장인물의 일관성을 유지하면서 이야기를 이어갈 때, 장면 사이의 어색함을 얼마나 줄일 수 있을까?

개별 장면의 완성도를 넘어 인물의 일관성과 이야기의 연속성을 함께 시험한 영상 작업이다. 공식 최종 편집본의 길이는 4분 0.96초다.

02 / 인물의 기준

그슨대

호리병 세계관의 최강 요괴. 호리병 속에 갇혀 있다가 해갈왕이 봉인을 풀면서 세상에 나온다.

해갈왕

조문국의 왕. 흉골군의 침공으로 위기에 몰리자 봉인된 그슨대를 풀어 나라의 위기를 넘긴다. 그러나 스스로 그슨대를 받아들이면서 요괴의 지배를 받게 된다.

흉골대장

조문국을 위협하는 흉골군을 이끄는 대장.

03 / 서로 다른 두 군대

조문국과 흉골군은 고대 아시아의 분위기를 바탕으로 한 퓨전 군대다. 보다 문명화된 조문국과 거칠고 야성적인 침략 군대인 흉골군의 대비를 시각적 기준으로 삼았다.

04 / 봉분과 사막 전장

이번 시퀀스의 무대는 멀티우주 어느 행성이다. 호리병을 가둬 둔 봉분과, 하늘에 세 개의 행성이 떠 있는 사막 전장을 배경으로 제작했다.

05 / 레퍼런스와 시작 프레임에서 얻은 발견

이번 작업에서는 기본 레퍼런스를 제공해 생성하는 방식과, 이미지를 시작 프레임으로 지정해 생성하는 방식의 차이를 체감했다.

호리병이 들어 있던 지역에서 벌어지는 전반부 에피소드는 기본 레퍼런스를 바탕으로 Seedance가 장면을 구성하도록 제작했다. 이번 결과를 비교했을 때는 이 방식의 장면 완성도가 더 높게 느껴졌다.

반면 이미지를 시작 프레임으로 지정한 장면에서는 이질감이 상대적으로 더 강했다. 이것이 도구를 다루는 숙련도의 차이인지, 입력 이미지의 특성이나 생성 방식에서 비롯된 것인지는 아직 단정하기 어렵다.

특히 시작 프레임을 활용하려면 입력 이미지부터 더 실사에 가까운 질감으로 만드는 노하우와, 반복 실험을 통해 축적한 자료가 필요하다고 느꼈다.

다음 작업에서 무엇을 더 연구해야 하는지 구체적으로 알게 된 것. 이것이 이번 제작에서 얻은 큰 성과 중 하나였다.

두 방식의 일반적인 우열을 단정하는 것이 아니라, 이번 작업에서 관찰한 결과와 배움을 기록한다.
