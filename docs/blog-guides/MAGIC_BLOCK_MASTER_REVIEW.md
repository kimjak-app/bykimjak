# MAGIC BLOCK MASTER — WATCH / MAKE 검수 기록

## 확정된 제작 사실

김작의 직접 설명을 기준으로 작성한다.

- 기획은 몇 년 전 시작했다. 애니메이션·게임·완구로 이어지는 비즈니스 모델을 가진 독립 IP를 목표로 한다.
- 초기 구상은 조립 블록을 마법으로 엮어 동물, 물건, 탈것, 최종적으로 로봇까지 만드는 장인들의 어린이 애니메이션이다.
- 장인들을 세계관 안에서 마법사라고 부르지 않고 **직공과 직녀**라고 부른다. 천을 짜듯 블록을 엮으며 레벨을 넘어 더 높은 능력으로 성장한다.
- 애니메이션 제작 방법을 몰라 아이디어로 간직하다가 Seedance 같은 영상 생성 도구의 등장으로 구현 가능성이 열렸다. 이 설명은 특정 버전이나 모든 컷의 생성 모델을 확정하는 근거는 아니다.
- 이번 최종 영상은 세계관과 작품의 성격을 소개하는 **3D 애니메이션 오프닝(OP)**이다.
- 기존 주제곡 `Weaver_of_the_Cube.mp3`를 OP 배경음악으로 사용했다.
- 최종 편집본은 70.506667초, 1280×720, 24fps, H.264/AAC이다. 원본명 `블랙매직마스터-20261012.mp4`와 작품 표제 `매직블록마스터`를 구분한다.

- Grok으로 생성한 `OLD/컨셉이미지1.png`, `OLD/컨셉이미지2.png`로 초기 로봇 대결 구상을 발전시켰다.
- 이번 영상 작업에서 민수가 멀티우주로 이동하고, 사라진 파로로 오해받아 세계를 구할 직공의 모험을 시작하는 이야기로 구체화했다.
- 파로는 두려움으로 자신의 운명을 거부해 어둠의 직공이 됐으며, 우리 세계에서 민수와 최후의 대결을 벌인다. 이 서사를 OP의 바탕으로 삼았고, OP 안에서 전체 이야기를 모두 보여준다는 뜻은 아니다.

- 공개 전시 자료: https://github.com/kimjak-app/bykimjak/releases/tag/media-magic-block-master-20261017
- 김작이 WATCH/MAKE 전시 자료의 공개 Release 업로드를 승인했다. 해당 검수본에 사용한 원본 56개(이미지 50개, OP 1개, OST 5개)와 이미지 썸네일 50개를 업로드했다.

- WATCH: `watch/magic-block-master.html`, MAKE: `make/magic-block-master.html`
- 검수 브랜치: `review/magic-block-master-watch-make`. main 배포 전이다.

## 츄파의 기원 — Wish

김작의 설명: 츄파는 준비 중인 단편 애니메이션 《Wish》의 주인공 중 하나이며 츄파카브라에서 영감을 받은 상상의 동물이다. 뜨개질 느낌의 Wish 캐릭터를 매직블록마스터의 3D 애니메이션 캐릭터로 발전시켜 민수의 모험 파트너로 등장시켰다. 다른 동명 작품과 연결하지 않는다. 첨부 Wish 이미지 두 장은 로컬 검수용으로만 연결했으며 공개 Release에 업로드하지 않았다.

## 민수와 루마 — 확정 인물 설정

김작의 직접 설명을 PAGE 01에 반영했다. 민수는 큐브 맞추기가 취미이며 공부와 학원 가기를 싫어하는 대한민국 초등학생이다. 누군가 선물한 마법의 큐브로 멀티우주에 가며, 같은 얼굴의 파로로 오해받는다. 자신의 능력을 모르고 마법을 쓸 줄 모르던 소년이 마스터 직공으로 성장하여 그 세계와 귀환 후 지구를 구한다. 선물한 사람의 정체는 미정으로 두고 창작하지 않는다.

루마는 파로의 여자친구이자 중급 직녀다. 누군가 민수를 납치하려 할 때 매직큐브의 힘으로 구하고 민수·츄파와 함께 파로를 찾아 떠난다. 납치 시도자의 정체나 루마가 오해를 푸는 시점은 임의로 추가하지 않는다. 이 설정 전체가 OP에 묘사됐다고 주장하지 않는다.

사용자가 지정한 시작/끝 이미지의 기존 자산 경로를 재사용하고 프롬프트 원문을 수록했다. Kling 3.0, 1280×720, 2026-10-08 오후 11:16은 사용자 제공 기록이다. 결과 파일 최종격돌.mp4는 ffprobe 기준 5.038730초, 3840×2160, H.264/AAC. 사운드 지시는 제공 프롬프트에 없으며 다른 사례의 무음악 조건을 적용하지 않는다. 공개 업로드 및 브라우저 검증은 미완료, 로컬 반영만 수행했다.
